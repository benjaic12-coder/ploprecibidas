# Plop Recibidas — Subida correcta a GitHub

IMPORTANTE: no subir desde celular si GitHub muestra los archivos sueltos.

La estructura correcta debe quedar así:

- index.html = home pública
- admin/index.html = panel privado
- assets/ = imágenes y logo
- netlify/functions/ = funciones de notificación
- supabase/ = scripts de base de datos

En GitHub deben verse carpetas como `admin`, `assets`, `netlify`, `supabase`, `js`, `css`.
Si ves `index (1).html`, `admin (1).js` o imágenes sueltas sin carpetas, la subida quedó mal.

Forma recomendada:
1. Descomprimir este ZIP en PC.
2. Abrir el repositorio en GitHub desde PC.
3. Add file > Upload files.
4. Arrastrar todo el contenido descomprimido respetando carpetas.
5. Commit: Version oficial limpia Plop Recibidas v22.
6. En Netlify: Deploys > Trigger deploy.
