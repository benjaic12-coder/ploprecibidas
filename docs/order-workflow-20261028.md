# Estados, seña, aprobación del diseño y mensajes · 28/10/2026

Acceso: Pedidos → Ver y gestionar → Gestionar estado, seña y diseño. Se mantienen los seis estados existentes y se agrega un selector explícito de aprobación del diseño, accesos rápidos y requisitos visibles. La seña proviene de los pagos verificados: un comprobante recibido no equivale a seña confirmada. Producción exige seña, diseño aprobado y cupo; entrega exige saldo verificado. Al quitar la aprobación durante producción, la propuesta vuelve a revisión y exige motivo. Cancelar o reactivar también exige motivo; no altera pagos ni devuelve dinero automáticamente.

El guardado de estado/diseño/notas usa una transacción con bloqueo, versión esperada y clave de idempotencia. Registra quién cambió el estado o la aprobación, cuándo y el motivo en una tabla privada. El historial anterior y las protecciones de pagos, capacidad y cupones permanecen. Se conserva la ruta anterior del backend para compatibilidad con sesiones abiertas del panel previo.

Se incorporan once plantillas: consulta/coordinación, seña pendiente, seña recibida, envío del diseño para aprobar, diseño aprobado, producción, saldo, entrega, entregado, cancelación y reseña. El mensaje usa los datos guardados, el saldo verificado y la configuración bancaria actual, sin notas internas. Las confirmaciones incompatibles con el estado se bloquean y no se muestra un texto falso como si ya hubiera ocurrido el hecho. Los mensajes se pueden editar/copiar o abrir en WhatsApp/email para revisión y envío manual. No se envía ningún mensaje por usar estos botones durante las pruebas. Se preservan los avisos automáticos existentes del backend.
