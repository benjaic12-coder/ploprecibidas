# Integración con la tienda Plop

Si Plop Seguimientos se publica dentro del mismo sitio que la tienda, agregar este botón en el menú público:

```html
<a href="/cliente/">Seguimiento de mi pedido</a>
```

Si se publica como un proyecto Netlify separado, reemplazar `/cliente/` por la URL completa del nuevo sitio.

El panel administrativo se abre desde `/admin/` y no debe mostrarse en el menú público.
